# E-Commerce Web Application

A modern and responsive e-commerce web application built with React.js that allows users to browse products, add items to a cart, and manage their shopping experience through a clean, intuitive interface.

---

## Features

- Browse products with a clean, modern UI
- Product listing and detailed product view
- Add to cart functionality
- Update item quantity or remove items from cart
- Dynamic price calculation based on cart contents
- Fast, lightweight, and responsive design
- Mobile-friendly interface across devices

---

## Tech Stack

- **Frontend:** React.js, JavaScript (ES6+), HTML5, CSS3
- **State Management:** React Hooks (`useState`, `useEffect`)
- **Tools:** Git, GitHub, VS Code
- **Deployment:** Render / Netlify

---

## Installation & Setup

Run this project locally by following these steps:

```bash
# Clone the repository
git clone https://github.com/Maynkbisht/EcommerceWebsite.git

# Navigate into the project folder
cd EcommerceWebsite

# Install dependencies
npm install

# Start the development server
npm run dev
```

The app should now be running locally. Check your terminal output for the local URL.
